This is a compilation of all of my Arduino IDE projects for Arduino R3 and ESP32. 

I'm always adding to this repo with my new ideas big or small. So far I've made:
-A digital, wireless thermometer that used esp-now to send temp and humidity data to 
  a node esp32 attached to an lcd screen.
-An RC Car and Tank model using a joystick attached to an esp32 that sends the 
  movement data via esp-now to an esp32 controlling the vehicles.
-A Joystick remote to control most of my RC projects that utilizes a joystick
-A pan/tilt desktop turret with a laser attached that has an auto mode to shine
  the laser on the ground randomly for my cats to play with but it also has
  a manual mode to control it with the joystick remote for fun!
-I have a window mounted A/C unit with a knob to adjust how cool it blows,
  so I created an automatic system that takes in a set temp from an IR remote/
  receiver and displays the current room temp and the set temp. When the current
  temp gets too high it uses an MG996 55g servo to turn the knob and adjust the 
  A/C unit to cool the temp in the room and vice versa when the temp gets too cold. 
-and more!

I use Legos primarily for my builds as I don't have access to a 3d printer yet, 
but Legos have served me well so far.
